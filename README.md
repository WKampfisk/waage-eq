# Waage EQ

Android equalizer project for Motorola Moto G06 Power and Bluetooth headphones.

## Status
Experimental Android audio effects implementation. System-wide EQ is **not guaranteed**: Android restricts attaching effects to other applications' audio sessions. Build and device testing pending.

## Local source
Version 0.3 source archive was prepared in ChatGPT. This repository currently contains the initial project setup notes; Android source import is the next step.

## Goal
10-band EQ, bass and balance presets, clipping-safe gain management, Bluetooth output handling, and downloadable APK via CI.
